# Белые воротнички · WhiteCollars

## Цель проекта

Разработать нейросетевой метод синтеза одного фазового дифракционного оптического элемента (ДОЭ) по четырём целевым изображениям. ДОЭ размером 128×128 сохраняется в одноканальном 8-битном PNG. Из сохранённой маски программа рассчитывает четыре реконструкции по Френелю на расстояниях 24,1, 25,3, 26,5 и 27,7 мм. Качество оценивается по SSIM и Pearson, отдельно измеряется время синтеза.

## Запуск через Docker

Нужен работающий Docker. Открой терминал в корне проекта и выполни:

```bash
docker build -t whitecollars:local .
docker run --rm -p 127.0.0.1:8000:8000 whitecollars:local
```

Открой [http://127.0.0.1:8000](http://127.0.0.1:8000). Все зависимости и обученные веса уже входят в образ. Если порт 8000 занят, замени `127.0.0.1:8000:8000` на `127.0.0.1:8080:8000` и открой порт 8080. Остановить приложение можно нажатием Ctrl+C в терминале.

1. Нажми **«Загрузить пример»** или выбери четыре своих PNG L8 размером **128×128**. Порядок плоскостей: **24,1 → 25,3 → 26,5 → 27,7 мм**.
2. Нажми **«Рассчитать ДОЭ»**. Сайт покажет маску, четыре реконструкции и две метрики на каждой плоскости, их средние по комплекту и время синтеза.
3. Скачай маску и нужные реконструкции. Фаза сохранена в 8-битном PNG, где 0 соответствует −π, а 255 соответствует +π.

## Терминальный запуск в Docker

Для одного прогноза без браузера:

```bash
docker run --rm -v "${PWD}/outputs:/app/outputs" whitecollars:local predict
```

Для своих изображений положи четыре файла в папку `inputs/` и выполни:

```bash
docker run --rm -v "${PWD}/inputs:/inputs:ro" -v "${PWD}/outputs:/app/outputs" whitecollars:local predict --images /inputs/01.png /inputs/02.png /inputs/03.png /inputs/04.png
```

Результаты появятся в новой папке `outputs/prediction-…/`: `doe.png`, `restored_1.png`…`restored_4.png`, `metrics.json` и `weights.npy` с картами важности. Для выбора набора или checkpoint доступны флаги `--manifest`, `--split`, `--sample` и `--weights`. В терминале также выводятся средние метрики и время синтеза. Справка: `docker run --rm whitecollars:local predict --help`.

## Пакетная оценка через Docker

```bash
docker run --rm -v "${PWD}/outputs:/app/outputs" whitecollars:local export --split validation --out outputs/val
docker run --rm -v "${PWD}/outputs:/app/outputs" --entrypoint doe-eval whitecollars:local evaluate --data src/dataset/example/validation --doe-dir outputs/val --device cpu --out outputs/metrics.csv
```

## Зависимости

В образ входят Python 3.12, PyTorch для CPU, NumPy, Pillow и scikit-image. Версии Python-библиотек закреплены в [requirements.txt](requirements.txt). Docker устанавливает их при сборке образа.

## Структура проекта

| Путь | Что в нём |
|---|---|
| `src/app/` | Локальный сайт и терминальные команды |
| `src/model/` | Синтез ДОЭ, общий запуск модели и обучение |
| `src/doe_eval/` | Френель, метрики и классический GS |
| `weights/` | Обученный checkpoint с описанием происхождения |
| `src/dataset/example/` | 150 четвёрок плюс диагностический пример |
| `src/tests/` | Проверки данных, оптики и прогноза с весами |

[Формат датасета и генерация](src/dataset/README.md) · [Происхождение весов](weights/README.md)

# Photonic Model

Проект для разработки, обучения и использования нейросетевой модели в задачах фотоники.

## Технологии

- **Python** — основной язык программирования.
- **uv** — управление зависимостями и виртуальным окружением.
- **Make** — автоматизация команд разработки.

## Структура проекта

```text
photonic_model/
├── src/
│   ├── main.py          # Точка входа
│   ├── app/             # Интерфейс приложения
│   ├── model/           # Нейросетевая модель
│   ├── dataset/         # Работа с данными
│   └── tests/           # Тесты
├── pyproject.toml       # Конфигурация проекта
├── uv.lock              # Зафиксированные зависимости
├── Makefile             # Команды разработки
└── README.md
```

### Описание модулей

- **`app/`** — пользовательский интерфейс приложения: терминальный, веб-интерфейс или другой способ взаимодействия с программой.
- **`model/`** — архитектура нейронной сети, её обучение и использование.
- **`dataset/`** — загрузка, подготовка и обработка данных для нейросети.
- **`tests/`** — тестирование компонентов проекта.
- **`main.py`** — основная точка входа в приложение.

## Установка и запуск

### Требования

- Git
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- Make (необязательно)

### Установка

Клонирование репозитория:

```bash
git clone <URL_репозитория>
cd photonic_model
```

Установка зависимостей:

```bash
uv sync
```

`uv` автоматически создаст виртуальное окружение `.venv` и установит необходимые зависимости.

### Запуск

```bash
uv run project
```

Или через Make:

```bash
make run
```

## Разработка

### Управление зависимостями

Добавление зависимости:

```bash
uv add <название_пакета>
```

Добавление зависимости для разработки:

```bash
uv add --dev <название_пакета>
```

Удаление зависимости:

```bash
uv remove <название_пакета>
```

Синхронизация зависимостей:

```bash
uv sync
```

Зависимости проекта описываются в `pyproject.toml`, а их точные версии фиксируются в `uv.lock`.

При изменении зависимостей необходимо сохранять изменения обоих файлов в Git.

### Makefile

Для автоматизации основных операций используется `Makefile`.

Содержимое:

```makefile
install:
	uv sync

run:
	uv run project

test:
	uv run pytest src/tests

lint:
	uv run ruff check src

format:
	uv run ruff format src

build:
	uv build

clean:
	rm -rf build/ dist/
	find src -type d \( -name __pycache__ -o -name "*.egg-info" \) -prune -exec rm -rf {} +
```

**Доступные команды:**

| Команда | Описание |
|---|---|
| `make install` | Устанавливает и синхронизирует зависимости |
| `make run` | Запускает приложение |
| `make test` | Запускает тесты через pytest |
| `make lint` | Проверяет код с помощью Ruff |
| `make format` | Форматирует код с помощью Ruff |
| `make build` | Собирает Python-пакет |
| `make clean` | Удаляет результаты сборки и временные файлы |

Для команд `make test`, `make lint` и `make format` необходимы установленные `pytest` и `ruff`.

Все команды выполняются из корневой директории проекта.

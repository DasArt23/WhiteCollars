# Формат датасета WhiteCollars

Сеть получает одну четвёрку целевых изображений и возвращает один фазовый ДОЭ. В комплекте есть `example/` с 100 обучающими, 25 валидационными и 25 тестовыми четвёрками. Четыре картинки диагностического примера хранятся отдельно в split `diagnostic`. Это небольшой процедурный пример для проверки формата и запуска. Он не гарантирует достижимость всех четырёх целей одной маской.

```text
src/dataset/
├── README.md
├── generate_dataset.py
├── diagnostic_source/
└── example/
    ├── manifest.json
    ├── diagnostic/0000/01.png … 04.png
    ├── train/000001/01.png … 04.png
    ├── validation/000001/01.png … 04.png
    └── test/000001/01.png … 04.png
```

## Изображения и физика

| Файл | Расстояние от ДОЭ |
|---|---:|
| `01.png` | 24,1 мм |
| `02.png` | 25,3 мм |
| `03.png` | 26,5 мм |
| `04.png` | 27,7 мм |

Каждый вход — одноканальный PNG 128×128 в режиме L, 8 бит. Яркость интерпретируется как **амплитуда** `PNG / 255`. Для обычных процедурных целей нужен чёрный фон и ненулевой сигнал. Ненулевой фон допускается для явно отмеченных физических целей. Реконструкции оцениваются после нормировки амплитуды по максимуму отдельно на каждой плоскости. Для Френеля используются 532 нм и шаг пикселя ДОЭ 10 мкм. Фаза маски кодируется в L8 от −π (0) до +π (255).

## Манифест

Формат `doe-manifest/1`. В `samples` лежат записи с уникальными `sample_id`. В каждой записи четыре пути относительно папки манифеста. Они принадлежат одному каталогу четвёрки, идут в порядке плоскостей и совпадают с `split` записи.

```json
{
  "format": "doe-manifest/1",
  "dataset_name": "example",
  "dataset_version": "example-v1",
  "distances_mm": [24.1, 25.3, 26.5, 27.7],
  "samples": [
    {
      "sample_id": "train_000001",
      "split": "train",
      "images": [
        "train/000001/01.png",
        "train/000001/02.png",
        "train/000001/03.png",
        "train/000001/04.png"
      ],
      "distances_mm": [24.1, 25.3, 26.5, 27.7],
      "seed": 123,
      "generator_version": "example-v1",
      "params": {}
    }
  ]
}
```

`train` предназначен для обучения, `validation` для выбора настроек, `test` для финальной проверки. Варианты одного исходника держите в одном сплите. Для смешанного набора используйте `params.kind`: `soft_independent` для независимо созданных целей и `physical_forward` для амплитуд, полученных из одной фазы. Контрольные маски храните отдельно и не включайте в `images`.

## Генерация и проверка

Команды выполняются из корня репозитория. Генератор записывает данные в новую папку и проверяет точные дубли, размер, фон и отступы. Большие наборы `data/` и `data_*/` игнорируются Git.

```bash
uv run --frozen python src/dataset/generate_dataset.py \
  --train 100 --validation 25 --test 25 --seed 905213 --out src/dataset/data_local
uv run --frozen python src/dataset/generate_dataset.py --verify src/dataset/example/manifest.json
```

# Результат аудита набора 1000/100/100

Дата: 7 ноября 2026. Статус: **технические проверки пройдены, распределение имеет ограничения**.
Это воспроизводимый отчёт проверок, не независимая сертификация.

## Подтверждено

- Все 4804 целевых PNG доступны, имеют формат PNG L 128×128, объект и фон.
- Точных пиксельных дубликатов во всём пакете нет.
- Порядок файлов и расстояний проверен; все объекты имеют поля вокруг сигнала.
- Все 1604 изображения исходного пакета 200/100/100 перечитаны с диска и совпали по пикселям.
- Состав замороженных validation/test/diagnostic сохранился.
- Загрузчик `model.data_connector.load_manifest` прочитал пакет 1000/100/100/1;
  последний элемент train имеет форму [4,128,128].
- Полный пакет восстановлен генератором v0.2.0: в ветке sand_DasArt манифест
  заявлял 1000 train, но файлов train/000201…001000 в дереве Git не было.

## Ограничения

Приближённый поиск при Пирсоне ≥0,95 нашёл:

| Сравнение | Найдено близких изображений / проверено запросов |
|---|---|
| validation → train | 3 / 400 |
| test → train | 1 / 400 |
| test → validation | 1 / 400 |
| выборка train → train | 4 / 300 |

Панель просмотрена: в основном это близкие положения простых кругов, эллипсов,
колец и других геометрических фигур. Точных копий нет. Найденные доли — нижняя
оценка для данного способа поиска, а не доказательство отсутствия прочих совпадений.

Существеннее другое: исходный генератор даёт только три сочетания семейств
внутри четвёрки, хотя отдельные изображения разнообразны. В 44,0% тренировочных
изображений пиксели яркостью ≥128 занимают менее 3% кадра; средняя такая площадь —
около 5%. Поэтому нужно смотреть восстановление объектов и обе метрики;
большая доля чёрного фона может влиять на интерпретацию качества.

Для текущего бюджета хакатона пакет пригоден как фиксированный процедурный
набор для сравнения методов. Обобщение на произвольные фотографии, все шрифты
или любые композиции этим набором не подтверждается. Изменения распределения
лучше исследовать отдельным экспериментом, сохранив нынешний тест.

Полные числа, хеш манифеста, версии библиотек и пути близких пар: `report.json`.

## Проверка инструментов

13 пройдено, 1 пропущен. Пропущенный старый тест ожидает `data/manifest.json`
в корне проекта, тогда как пакет расположен в `src/dataset/data/`.
Реальный пакет отдельно проверен полным вызовом загрузчика по правильному пути.
Регрессии аудита покрывают повторную генерацию, точный дубль между выборками,
отсутствующий файл, RGB вместо L, изменение замороженного пикселя,
перестановку каналов и предупреждение о почти-дубликате.

# Результат проверки Soft600

Пакет готов к подключению к обучающему коду. **Обучение модели Максима на нём
ещё не выполнено**, рост её метрик не подтверждён. Инструкция:
[SOFT600.md](../SOFT600.md). Вход `src/dataset/data_soft600/manifest.json`.
Отключить аугментации каналов/геометрии, начать с 4–8 train-примеров.

## Данные

600 train = 360 мягких независимых + 240 физически согласованных четвёрок.
100 validation и 100 test, в каждом 60/40 тех же групп. Диагностика А1
сохранена отдельно. Всего 3204 целевых PNG и 320 контрольных фаз; фазы
лежат вне папок целей и не являются входами сети.

Процедурные цели имеют плавные края и крупные объекты. Средняя доля ярких
пикселей train — 16,80% вместо 4,97% у старого процедурного набора;
в новом процедурном наборе каждый объект занимает не меньше 6% ярких пикселей.
У физического поднабора другая статистика: яркие спекл-пики занимают в среднем
3,69%, средняя амплитуда 0,129. Его нельзя описывать как «просто размытые PNG».

## Проверки целостности

- 3204 целевых изображения: PNG L 128×128, правильный порядок плоскостей.
- Точных дубликатов целевых изображений: 0, включая пересечения split.
- Пересечений с 4800 старыми недиагностическими PNG: 0.
  Общие четыре изображения А1 исключены из этой проверки намеренно.
- 800 уникальных origin/seed, 320 уникальных контрольных фаз.
- Каждая физическая четвёрка побитово совпадает с рассчитанными из её PNG-фазы
  целями: максимальная ошибка 0 уровней яркости.
- Независимый float64-расчёт через матрицу ДПФ для трёх train-фаз отличается
  максимум на 1/255 после квантования; это проверка численного согласования.
- Повторная генерация: 3204 целевых + 320 фазовых PNG совпали побайтово.
  Контрольные фазы при финальной упаковке вынесены в отдельную папку;
  сравнение сделано по sample_id. Исходники, версии и seed записаны в манифесте.
- Реальный загрузчик успешно прочитал полный пакет. Отдельный обратный проход
  существующего physics loss дал конечные ненулевые градиенты.
  Это проверка соединения данных с физикой, не обучение нейросети.
- 18 автоматических тестов пройдены, 1 прежний тест пропущен из-за ожидания
  устаревшего пути `data/manifest.json`. Реальный новый путь проверен отдельно.

## Похожие изображения: честное ограничение

Статус машинного аудита: **review_required**, ошибок целостности 0.
При пороге Пирсона 0,95 найдены похожие отдельные изображения:

| Сравнение | Сколько запросов имеют близкий пример |
|---|---:|
| Validation → train | 14 / 400 |
| Test → train | 9 / 400 |
| Test → validation | 1 / 400 |
| Выборка train → train | 7 / 300 |

31 сохранённая пара просмотрена на `near_pairs_01…03.png`: это преимущественно
близкие круги/эллипсы, многоугольники и одинаковые символы с вариациями размера,
поворота, яркости и дефектов. Происхождения/seed различаются; буквального
копирования нет. Такие варианты не доказывают перенос на новые классы объектов.
Предупреждения не скрыты и изображения из test по ним не отбирались.

Дополнительный поиск по **упорядоченным четвёркам** не нашёл среднюю
поканальную корреляцию ≥0,95: максимум 0,805 validation→train и 0,786
test→train среди проверенных кандидатов. Оба поиска приблизительные:
top-5 кандидатов по 32×32, проверка на 128×128, без инвариантности к сдвигу/
вращению. Это не доказательство отсутствия любых семантических повторений.

## Небольшой расчётный эксперимент

Первые 12 train-четвёрок каждой группы; один и тот же существующий GS,
60 итераций, seed=42, CPU, одинаковая физика и нормировка, сохранение/
перечитывание фазового PNG, квантование восстановлений. Для контроля резкости
взяты те же старые цели с Gaussian blur σ=2 и повторной max-нормировкой.
Порядок примеров определён до расчёта. Validation/test метрики не использованы.

| Цели | Пирсон | Глобальный SSIM | Оконный SSIM |
|---|---:|---:|---:|
| Старые | 0,527 | 0,357 | 0,105 |
| Те же старые, только размытие σ=2 | 0,525 | 0,381 | 0,124 |
| Новые мягкие независимые | 0,719 | 0,549 | 0,103 |
| Новые физически согласованные | 0,912 | 0,902 | 0,589 |

Глобальный SSIM — текущая `doe_eval.metrics.ssim_global` (популяционные моменты,
K1=0,01, K2=0,03, диапазон 1). Оконный — текущая `ssim_skimage`, стандартное
окно 7×7, data_range=1; не гауссово окно σ=1,5. Если команда выбирает другой
протокол, пересчитать обе сравниваемые модели одинаково и явно подписать его.

**Вывод:** одно размытие почти не изменило корреляцию. Новые мягкие цели
лучше согласуются с GS по глобальным метрикам, но локальная структурная
метрика для них не улучшилась. Физический поднабор даёт более высокое качество
в этом опыте; это другая, специально согласованная задача.
По 12 примерам нельзя гарантировать поведение на всём наборе или рост метрик
нейросети. Полученные числа не являются финальной test-оценкой.

Маска, из которой сгенерирована физическая цель, не подставлялась в GS.
GS запускался независимо с seed=42. Проверка с известной контрольной фазой
находится в аудите и не включена в таблицу качества методов.

Артефакты: `audit.json`, `reproducibility.json`, `gs_train_check/report.json`,
`gs_train_check/comparison.png`, панели похожих пар и `targets_overview.png`.
Исходные PNG другого участника не опубликованы и не входят в обучение.

Повторить эксперимент (выбрать новую папку):

```bash
PYTHONPATH=src uv run python -m dataset.benchmark_soft_dataset --old src/dataset/data/manifest.json --new src/dataset/data_soft600/manifest.json --out runs/soft600_gs_check --samples 12 --iters 60
```
